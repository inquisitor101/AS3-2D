# Class hierarchy and dependencies {#diagrams}

These diagrams are generated from the current source code each time the
documentation is built. Click a class in a diagram to open its reference page.
Open a diagram at full size for closer inspection. Larger dependency diagrams
include controls for zooming and panning.
